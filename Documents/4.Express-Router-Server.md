##### Express = Framework giúp viết API

##### Routes = Đường API (Tập hợp URL xử lý từng chức năng)

##### Server = Nơi chạy Express (Chạy Express và lắng nghe request)



🚀 Express



Là một framework chạy trên Node.js giúp bạn:



tạo web server



khai báo API endpoints (GET/POST/PUT/DELETE)



dùng middleware (cors, body-parser, jwt,…)



tổ chức code gọn và dễ mở rộng



import express from "express";

const app = express();



🛣️ Routes



Là các đường dẫn API mà frontend sẽ gọi đến backend.

Mỗi route tương ứng một chức năng.



Ví dụ file routes/notes.ts

import { Router } from "express";

const router = Router();



router.get("/", (req, res) => {

&nbsp; res.send("Get all notes");

});



router.post("/", (req, res) => {

&nbsp; res.send("Create note");

});



export default router;





🖥️ Server



Là nơi Express chạy và lắng nghe request từ client.



import express from "express";

const app = express();

const PORT = 5000;



app.listen(PORT, () => {

&nbsp; console.log(`Server running on port ${PORT}`);

});



###### 

###### **Client → gửi request → Express Server → tìm đúng route → xử lý → trả response → Client nhận dữ liệu**
